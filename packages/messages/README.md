# @gene/messages — сообщения (ЗАГЛУШКА с правильным каркасом, ТЗ 6.3)

`renderEvents(events, viewerId, { seed, turn })` превращает структурированные события `core` в строки лога
(`LogMessage`). Модуль отвечает только за выбор шаблона, склонение и подстановку. Тексты шаблонов, глаголы,
причастия и словоформы лежат в `packages/data/src/messages.ts` и в данных сущностей (`WordForms`).

Вызывается на сервере перед отправкой клиенту. Вариант шаблона выбирается сидированным ГПСЧ (сид партии + номер хода),
поэтому при повторе лога команд после перезапуска сервера тексты совпадают.

Синтаксис шаблонов описан в корневом `README.md` («Шаблоны сообщений»). Чтобы заменить тексты, достаточно править
`data/src/messages.ts`; чтобы заменить механизм — этот пакет, сохранив сигнатуру `renderEvents`.
