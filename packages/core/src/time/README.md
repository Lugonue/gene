# time — модель времени (ЗАГЛУШКА)

Очередь ходов и стоимость действий. Остальной код `core` вызывает только функции из `index.ts`:

- `actionCost(creature, action)` — стоимость действия в aut. Сейчас: все действия 10 aut, делённые на скорость
  существа (норма 10, варг 15), движение дополнительно умножается на `moveCostMultiplier` из модуля формул
  (искалеченные `stance`-части замедляют).
- Замедление холодом: `applySlow(creature, now)` — действия дороже в `SLOW_COST_MUL` раз в течение `SLOW_DURATION` aut
  (числа — в модуле формул; повторный холод продлевает), `isSlowed`, `expireSlow(creature)` — снять истёкшее (мир вызывает перед ходом существа).
- `spendTime(creature, cost)` — сдвинуть момент следующего хода.
- `nextActor(state, depth)` — кто ходит следующим на уровне (наименьший `nextActAt`, при равенстве — игрок).
- `syncLevelTime(state, depth)` — при входе на уровень его существа не могут «ходить в прошлом».

Чтобы заменить модель (разная стоимость действий, ускорение/замедление, энергия), достаточно переписать этот модуль,
сохранив сигнатуры.
