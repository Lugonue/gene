# Магические типы урона

Status: ready-for-agent
Type: task

Спека: `../spec.md` (раздел «Типы урона и материал»).

## Что сделать

- Типы урона `fire`, `cold`, `lightning`.
- Множители по материалу части тела: `fire` сильнее бьёт по органике, `lightning` — по бионике (числа — в модуле формул).
- `cold` вместо лишнего урона замедляет цель на несколько ходов (через модуль времени).
- Шаблоны сообщений для новых типов: ожог, обморожение, разряд, сбой бионики от молнии.

## Приёмка

- Тесты множителей для органики и бионики.
- Тест замедления: цель под `cold` ходит реже, эффект проходит.
- Тест сообщений: все части тела × новые типы × исходы.
