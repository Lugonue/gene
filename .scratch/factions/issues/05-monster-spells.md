# Заклинания монстров: перезарядка, усталость, срыв

Status: ready-for-agent
Type: task
Blocked by: 03, 04

Спека: `../spec.md` (раздел «Магия монстров»).

## Что сделать

- Данные заклинаний: огненный шар, огненный плевок, ледяная стрела, молния, лечение. Для каждого — явление, к которому оно относится, урон, дальность, базовая перезарядка.
- Заклинания у видов — по таблице спеки (атаман и вождь не колдуют).
- Перезарядка у каждого заклинания.
- Усталость монстра растёт с каждым заклинанием и спадает со временем; она повышает шанс срыва и удлиняет перезарядку. Формулы — в модуле формул.
- Срыв: ход и перезарядка потрачены, эффекта нет, есть сообщение.
- Снаряды — через механизм задачи 03.
- Лечение: маг лечит раненого союзника в поле зрения.
- ИИ мага: держит дистанцию, колдует при линии огня и готовом заклинании, лечит союзников, в углу бьёт посохом.
- Сообщения: колдовство, попадание, срыв. Усталость описывается словами («шаман выдохся»).

## Приёмка

- Тест: с ростом усталости растут шанс срыва и перезарядка; со временем усталость спадает.
- Тест: срыв тратит ход и перезарядку и не даёт эффекта.
- Тест: маг лечит союзника и не колдует через союзника.
