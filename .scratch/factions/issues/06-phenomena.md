# Явления: данные Ядра и описания рецептов

Status: resolved
Type: task
Blocked by: 05

Спека: `../spec.md` (раздел «Явления и база знаний»).

## Что сделать

- Явления в базе знаний: огненный шар (сюда же огненный плевок), ледяная стрела, молния, лечение. До изучения у них условные имена («термическая аномалия №1»).
- При первом наблюдении — сообщение Ядра «[ЯДРО] Зафиксировано неизвестное явление: …».
- Источники данных: заклинание в поле зрения (мало), попадание по киборгу (больше), сорвавшееся заклинание (мало). Числа — в модуле формул.
- Стадии: неизвестно → частично → изучено; при каждом переходе — сообщение Ядра.
- Изучено → рецепт открыт: сообщение с названием и описанием (поджог оружия, охлаждение, разряд через оружие, ускоренная регенерация органики). Применять рецепты пока нельзя.
- `PlayerView`: список явлений с именем по стадии, процентом до рецепта и описанием открытого рецепта.

## Приёмка

- Тесты источников данных и порогов.
- Огненный шар разных заклинателей и огненный плевок копят одну шкалу.
- `PlayerView` не раскрывает настоящее название неизученного явления.
