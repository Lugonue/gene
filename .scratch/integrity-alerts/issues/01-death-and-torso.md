# Киборг гибнет только от целостности; искалеченный торс усиливает урон

Status: ready-for-agent
Type: task

Спека: `../spec.md`, ADR: `docs/adr/0003-kiborg-gibnet-tolko-ot-celostnosti.md`.

## Что сделать

- `core/src/combat/attack.ts`: у игрока vital-смерти нет, остаётся только `target.hp <= 0`. У монстров всё как раньше.
- Голова и торс игрока не переходят в `severed`, стадия ограничена `crippled`. В представлении на 0 hp — «разрушена» (органика) или «отказ» (бионика). Голова на 0 hp влияет на зрение как искалеченная.
- Модуль формул: множитель урона по целостности от стадии торса (`crippled` ×1.5, 0 hp ×2) для всех существ.
- Шаблон `death.player.vital` больше не нужен — убрать его или оставить мёртвым, по месту.
- Запись в `DECISIONS.md`.

## Приёмка

- Тест: игрок с головой на 0 hp и целостностью > 0 жив; монстр в той же ситуации гибнет.
- Тест: удар по искалеченному торсу снимает с целостности в 1.5 раза больше, чем по здоровому.
