# Цифры входящего урона в журнале

Status: ready-for-agent
Type: task

Спека: `../spec.md`.

## Что сделать

- В событие `attackHit` по игроку добавить то, чего в нём не хватает для строки цифр: целостность после удара, hp задетой части и её максимум.
- В сообщении журнала завести отдельное поле для мелкой служебной пометки. Не дописывать её в `text`, чтобы не ломать сворачивание одинаковых сообщений и не смешивать повествование с цифрами.
- Формат: `−7 · броня −3 · Целостность 18/40 · голова 3/12`. Фрагмент про броню — только если поглощено > 0. При полном поглощении — `урон заблокирован`, без цифр.
- `MessageList.vue`: пометка мелким шрифтом в той же записи. Только для ударов по игроку.

## Приёмка

- Тест сообщений: удар по игроку даёт пометку с цифрами, удар по монстру — без пометки, полное поглощение — «урон заблокирован».
