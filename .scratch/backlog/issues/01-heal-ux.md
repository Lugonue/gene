# Лечение без лишних действий

Status: resolved
Type: task

## Идея

Механика исправления повреждений через клавишу `Q` должна быть максимально дружелюбной:

- Выбираешь, например, «перевязку» — если ты полностью здоров, игра прямо сообщает
  «Я полностью здоров» и не тратит ход/ресурсы.
- Не предлагать лечебные действия, которые нечего лечить (уже здоровая часть тела,
  уже вылеченный объект).

## Открытые вопросы

- Скрывать неприменимые действия из меню или показывать их неактивными с причиной?
- Что считается «объектом» лечения: персонаж целиком, части тела, союзники?
- Должна ли проверка тратить ход (нет — по умолчанию)?
