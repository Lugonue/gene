# Лечение без лишних действий

Status: resolved

Из бэклога: `../backlog/issues/01-heal-ux.md`. Окно применения — клавиши `a`/`q` (`client/src/input.ts`), выбор цели — `client/src/components/TargetModal.vue`, действие — `useAction` в `core/src/actions/items.ts`.

## Решения

- Неприменимые цели **скрываются**: в окне бинта — только повреждённые органические части; в окне ремкомплекта — только повреждённые бионические части и предметы с неполной прочностью.
- Если целей нет, окно не открывается; в журнал — сообщение («Я полностью здоров.» / «Чинить нечего.»), ход и предмет не тратятся.
- Зелье лечения при полном HP и всех неповреждённых частях не выпивается: отказ «Я полностью здоров.», ход не тратится. Проверка — в ядре (`useAction`, новая причина отказа), клиент лишь не тратит запрос впустую.
- Проверки ничего не стоят (не тратят ход).
